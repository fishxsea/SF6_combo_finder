# Published-route coverage

Reviewed October 7, 2026. These counts describe complete stored recipes, not
the number of search results: searches include attack-ending prefixes and
deduplicate routes. Imports expand only explicitly published alternatives.

**Official trial coverage is incomplete for every character.** Twenty-three
historical Capcom Combo Trial transcriptions are included for Ryu and A.K.I.
via Prima Games. Other fighters currently have community recipes only. No
routes have been verified in training mode on the current patch.

The SF6 Lab import reviews the essential starter sections (Manon’s basic combo
section), not every page section. Ambiguous strength/charge/resource variants,
negative examples, incomplete strings, blocked DI states and setup sequences
are excluded. Machine-readable entry numbers and reasons are stored in
`data/documented_routes.json` under `coverage`; source URLs are in `sources`.
